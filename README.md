# 💫 About Me

Frontend Developer with 3+ years of experience, currently deepening into full-stack engineering.

I work on **Roll Inn**, a live multi-tenant SaaS food ordering platform serving 100+ restaurant sites from a single codebase — real-time order management via SignalR, PWA support, and dynamic multi-tenant theming.

Right now I'm building out the backend half of my stack — Node.js, Express, PostgreSQL, and auth from scratch — with the goal of becoming a strong full-stack engineer working toward AI application engineering. I document the entire process publicly: daily notes, working code, and LinkedIn posts as I go.

- 🔭 Currently building: a Node.js/TypeScript/Express backend from raw fundamentals up — no shortcuts, no black boxes
- 🌱 Learning in public: [`backend-learning-journey`](https://github.com/Samad-Developer/backend-learning-journey) — daily, working code with notes
- 🎯 Goal: Full-stack → AI application engineering
- 💬 Ask me about: React/Next.js architecture, Redux Toolkit vs Zustand, or how a raw HTTP server actually works under the hood
